# AI Log

## Project

I Am Alive — Animal Shelter Website

## How AI was used

AI assistance was used as a learning and development aid during the HTML coursework.

### 1. Planning
AI helped break the assignment requirements into separate website pages and identify the required HTML elements.

### 2. HTML structure
AI helped draft and explain the structure of:
- `index.html`
- `animals.html`
- `help.html`
- `colophon.html`

The code was reviewed and tested by the student in VS Code.

### 3. Content organization
AI helped organize publicly available shelter information into sections, articles, tables, lists, quotations and contact information.

### 4. Form
AI helped construct an educational HTML form containing labels, fieldsets, a legend, input types, radio buttons, a checkbox, a select element, a textarea and submit/reset controls.

### 5. Images
AI helped identify a published source containing authentic photographs connected to the I Am Alive shelter. The photographs were saved locally by the student and used in the project.

### 6. Task A and Task B
AI helped structure the analysis of a real animal-welfare website and draft the explanation of how a browser processes HTML.

## Student responsibility

The student created and edited the project in VS Code, saved the files, checked the pages in a browser, checked image paths, and is responsible for reviewing the final content before submission.

## Important limitation

AI was not used to generate or replace the required authentic shelter photographs. The website uses locally saved photographs from a published source.


## Midterm preparation update (2026-10-09)

AI was used to review the project against the Midterm requirements and suggest focused changes while preserving the existing page layout and Bootstrap approach. The work included preparing a realistic support-request form using an external email-forwarding service, adding form/result hooks and CSS state classes, drafting three user journeys, and adding a manual quality-pass checklist. The student must configure and verify the form recipient, test the website in a browser, run the W3C validator, update current screenshots, and review the changes before submission.


## Assignment 4–5 assistance log (2026-10-29)

AI assistance was used to review the Assignment 4–5 requirements and prepare a vanilla-JavaScript implementation for the existing project. The implementation adds `js/main.js`, `js/index.js`, `js/animals.js` and `js/help.js`; adds only deferred script links to existing HTML pages; and updates this README with the functionality plan and checklist. The code is intended for the student to review, test and explain. It creates no backend and the support form is handled as a local front-end demonstration; no request is submitted to FormSubmit by the JavaScript flow.
