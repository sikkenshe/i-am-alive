About This Project

This website was created as an individual academic project for the Introduction to Web Technologies course.

The project presents publicly available information about the I Am Alive animal shelter in Astana, Kazakhstan.

Author

Student Information

Technologies Used

The website uses HTML only.

The document structure follows basic WCAG principles where applicable.

  • HTML5
  • Semantic HTML elements
  • HTML forms
  • HTML tables
  • Relative navigation

No CSS is used in this assignment.

No JavaScript, frameworks, templates or external UI libraries are used.

Semantic Structure

The project uses semantic elements to describe the purpose of different parts of the page.

Header
Contains the main introductory information of a page.
Navigation
Contains links between the four pages.
Main
Contains the primary content of each page.
Section
Groups related content into meaningful sections.
Article
Contains a self-contained piece of information.
Aside
Contains additional information related to the main content.
Footer
Contains closing information and project details.

Forms and Server Limitations

The How to Help page contains an HTML form with different input types, labels, radio buttons, a checkbox, a select menu, a textarea and submit/reset controls.

The form is included for educational purposes. It does not currently send or store information because the project does not have a server-side application.

The form therefore demonstrates the HTML structure of a form, rather than providing a real online submission service.

Project Limitations

  • No CSS is used.
  • No JavaScript is used.
  • No backend server is connected.
  • Information may change over time.
  • Current shelter information should be confirmed directly.
